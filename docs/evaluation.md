# The evaluation method

How a claim is earned in this lab. A result here is not "it did the thing
on video" — it is "it did the thing N independent times, with learning
frozen, on material it was never shown, while everything it learned before
still works."

This is the discipline the lab applies to itself. It is also the lens the
lab uses when examining other people's work (see the
[FlyBridge audit](../reports/2026-10-04-flybridge-audit.md)).

## The checks

1. **Baseline before teaching.** Run the task with the untrained system,
   on a fixed number of independent seeds, and record it. "0/6 before,
   12/12 after" is the shape of a claim; "12/12" alone is a number.
2. **Frozen checks.** A skill counts as learned only when it passes a full
   batch of independent checks **with learning switched off**, on seeds
   excluded from training material. The batch size used in this lab is
   **12 independent checks, all required**; two batches of 6 count as the
   same thing.
3. **Retention.** After every new skill is added, *all previous* skills are
   re-run as frozen checks with the same weights. A new skill that breaks
   an old one is not a pass — it is a regression, and the weight state is
   what gets blamed (and rolled back or restructured), not the luck of the
   day.
4. **Negative labels.** Training material labels **every option in a
   situation**, not just the chosen one: productive / neutral / impossible
   / damaging. Systems that only see right-answers learn the teacher's
   path, not the world's constraints; they fail the first time the path
   is not available.
5. **Worksheets.** For situations the teacher never visits (off-distribution
   states: the just-planted field where the right answer is *wait*, the
   empty pockets where the right answer is *don't go to the chest*),
   practice material is **generated by perturbing real recorded states** —
   not by more demonstrations. Generated material is labelled as
   generated.
6. **Hidden exam.** A locked set of examples, never used for training, is
   scored after every training cycle; the best-scoring version is kept.
   The gap between training score and exam score is reported — a widening
   gap is memorization, and the exam, not the training curve, decides what
   is kept. The exam is a **smoke alarm, not a verdict**: only the frozen
   live checks pass or fail a skill.
7. **The control-wiring bar.** No claim in this lab of the form "the
   biology helps" is made without the matched controls: the **fly** wiring,
   a **shuffled** wiring (same size, same degree distribution, same sign
   balance, random connectivity — seed recorded), and a **disconnected**
   wiring (same neurons, no connections), all run on the *same* task
   battery with the *same* training budget. If the shuffled network does
   the same thing, the honest result is "the wiring did not matter for
   this task" — and that is a publishable finding, not a failure.

## What gets reported

Every experiment reports, per check batch: seeds used, pass/fail per seed,
failure mode (not just failure count), wall time, and the exact weight
state (hash) that produced the result. A failed take is kept in the log —
a run log that only contains successes is not a log, it is marketing.
